# TypeSafe Jev 1.14 as a CQA scorer (experiment)

Jev (`typesafe/jev-1.14`) is a "decision model" served by OpenRouter's alpha Decisions API
(`POST https://openrouter.ai/api/alpha/decisions`). It takes a free-text `state` and a set of typed
questions and returns probabilities — no free text, **no evidence quotes**.

Code: `cqa/jev.py` (adapter), `scripts/bench_jev.py` (benchmark, tie-break analysis), `tests/test_jev.py`.
Results: `results/jev/` (force-added; `truncated700/` = the first, worse variant).

## Mapping (one API call per dialog)

| checklist | Jev question |
|---|---|
| binary YES/NO[/NA] | `choice` with options `yes`/`no`[/`na`]; option texts = the rubric lines |
| scale | `score`, criteria = rubric steps in ascending order; most-probable index → scale value (Jev's `score` is an expectation like 2.4, so we take argmax of `probabilities`) |
| scale with NA (04) | extra `noul` "not applicable?"; p>0.5 → NA |
| gross (08) | `choice` yes/no |

`state` = role statement (judge only the human operator; bot greeting/farewell doesn't count) +
the code-computed ФАКТЫ block + numbered transcript (head+tail truncation above 12k chars).
`instructions` = criterion name + rubric + rules from the YAML. Output: our internal values,
`confidence` = Jev's probability of the chosen option, `evidence=[]`, justification
`decision model (Jev) p=..`, `needs_review` if p<0.7.

**Rules must not be truncated.** With rules cut to 700 chars agreement was 0.880 gold / 0.858 held-out
(06 systematically 10→7, 02 NA→NO). With the full rules (default, `CQA_JEV_RULES_CHARS=0`) it jumps by ~9 pts.
That choice was made after seeing both sets, so the held-out number is only semi-held-out.

## Caveats

- Tiny sample (26 dialogs, 208 labels); gold is synthetic and labelled by us; a 1-label difference = 0.5–1 pt.
- No evidence quotes → cannot satisfy the guide's "reply-evidence" requirement on its own.
- Alpha API, prompt/instruction format not documented; model id resolves to `typesafe/jev-1.14-20261014`.
- Run-to-run variance is small but nonzero (held-out 0.925–0.938).
- Not wired into `Evaluator`/presets/the `/models` matrix: `results/bench_matrix.json` is regenerated by
  `scripts/bench_matrix.py` and its rows assume token-based usage; numbers live in `results/jev/` instead.

## Recommendation

Do not replace the LLM scorer. Plausible uses: (1) a near-free pre-pass/router — run Jev on every dialog and
send low-confidence (p<0.7) criteria or dialogs where Jev disagrees with a cheap model to the jury;
(2) a second-opinion signal for `needs_review`. Not as the jury tie-breaker (no gain over the opus judge).

Cost of this experiment: OpenRouter key limit_remaining $0.4872 → $0.4164 (spent $0.071;
matches the summed per-call `usage.cost` for ~157 calls).
